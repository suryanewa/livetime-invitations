Frame cost, v1.6 flames polish 2. M2 Pro, Chrome/Metal (ANGLE), headless, the live stage held at a
moment (Stage.render only: the scene's update, the smoke physics included, is not in these numbers);
each frame waited on with a 1-pixel readPixels; alternating 12-frame batches per case, 16 batches,
medians, timed from node (the page's clock is Playwright's fake one). The machine was shared with
other owners' servers: absolute times run high, batch-to-batch noise ~0.2-0.3 ms; the differences
are the costs. Cases: full; nofx = no flame quads (volumes + twins), no bloom, no haze, no smoke
(volume, ribbons); nosmoke = the smoke's volume and ribbons hidden; nobloom; nohaze.

Budget: the whole fire <= 2.0 ms at both sizes: met.

The smoke's physics on the main thread (node, the same code): 0.76 ms a frame while smoke shows
(6 candles x 5 strands x 96 parcels, the plume's path computed once a candle), was 1.32 ms on
v1.6/integration (6 x 3 x 64). None while the flames burn. With it the smoke at 1.5 s is
0.81 + 0.76 = 1.57 ms (laptop), 1.51 ms (phone).
